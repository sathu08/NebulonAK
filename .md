
## What `DecisionAgent` does

The important part is that **DecisionAgent doesn't implement the actual business task**.

It decides:

```text
User Request
     │
     ▼
DecisionAgent
     │
     ├── Existing agent can handle?
     │          │
     │          └── YES → select agent
     │
     ├── No suitable agent?
     │          │
     │          └── Create Agent
     │
     └── Need more information?
                │
                └── Ask user
```

For example:

```text
User:
"Read this Excel file and find duplicate suppliers"

              │
              ▼
        DecisionAgent
              │
              ▼
     Does ExcelAgent exist?
          /          \
        YES           NO
         │             │
         ▼             ▼
   ExcelAgent      AgentCreator
         │             │
         │             ▼
         │        Create ExcelAgent
         │             │
         └──────┬──────┘
                ▼
           ExcelAgent
```

                    ┌─────────────────────┐

## `DecisionAgent/agent.py`

Keep the agent itself simple:

```python
from nak.brain.client import BrainClient
from .models import DecisionResult


class DecisionAgent:
    """
    Decides which agent should handle a user request.
    """

    name = "DecisionAgent"

    def __init__(self, brain: BrainClient):
        self.brain = brain

    async def decide(self, user_request: str) -> DecisionResult:
        """
        Analyze the request and decide what should happen.
        """

        # 1. Send request to LLM
        # 2. Parse structured decision
        # 3. Return DecisionResult

        response = await self.brain.generate(
            user_request
        )

        return self._parse_response(response)

    def _parse_response(self, response) -> DecisionResult:
        ...
```

The exact `brain.generate()` call should match your existing `nak/brain/client.py`.

## `DecisionAgent/models.py`

I recommend keeping the decision result structured.

```python
from dataclasses import dataclass, field


@dataclass
class DecisionResult:
    action: str

    agent_name: str | None = None

    reason: str = ""

    confidence: float = 0.0

    parameters: dict = field(default_factory=dict)
```

Possible actions:

```text
USE_AGENT
CREATE_AGENT
ASK_USER
```

So the LLM should ultimately produce something conceptually like:

```json
{
    "action": "USE_AGENT",
    "agent_name": "ExcelAgent",
    "reason": "The request requires Excel file processing",
    "confidence": 0.94
}
```

Or:

```json
{
    "action": "CREATE_AGENT",
    "agent_name": "ExcelAgent",
    "reason": "No existing agent can process Excel files",
    "confidence": 0.91
}
```

# `nak/prompts/decision.py`

Keep the decision prompt outside the agent implementation:

```python
DECISION_AGENT_PROMPT = """
You are DecisionAgent.

Your responsibility is to analyze a user request and determine
which agent should handle it.

You must choose one of:

1. USE_AGENT
   Use an existing agent that can satisfy the request.

2. CREATE_AGENT
   No existing agent is suitable, so a new agent is required.

3. ASK_USER
   The request is too ambiguous or missing required information.

Return a structured decision.

Do not perform the requested task yourself.

User request:
{user_request}

Available agents:
{available_agents}
"""
```

This separation is useful:

```text
DecisionAgent
      │
      ├── agent.py       → decision logic
      │
      └── models.py      → decision structure

prompts/
      └── decision.py    → LLM instructions
```

# Most important part: Agent folder

Since you said **"agent need to use agent folder"**, I would make this a strict convention:

```text
nak/agents/
│
├── DecisionAgent/
│   ├── __init__.py
│   ├── agent.py
│   └── models.py
│
├── AgentCreator/
│   ├── __init__.py
│   └── agent.py
│
├── PlanningAgent/
│   ├── __init__.py
│   └── agent.py
│
├── ExcelAgent/
│   ├── __init__.py
│   └── agent.py
│
└── PDFReaderAgent/
    ├── __init__.py
    └── agent.py
```

Then your future self-creation flow becomes:

```text
                     User
                       │
                       ▼
                DecisionAgent
                       │
                 "What agent?"
                       │
             ┌─────────┴─────────┐
             ▼                   ▼
       Agent exists          Agent missing
             │                   │
             ▼                   ▼
       Load Agent          AgentCreator
                                 │
                                 ▼
                         /nak/agents/
                                 │
                                 ▼
                         NewAgent/
                         ├── __init__.py
                         └── agent.py
```

### One architectural rule I strongly recommend

**Don't put agent discovery/creation code directly inside `DecisionAgent`.**

Instead:

```text
DecisionAgent
      │
      ├── decides WHAT to do
      │
      └── delegates HOW to do it
                │
                ├── existing agent
                │
                └── AgentCreator
```

That gives you a clean foundation for your self-creating agent system.

Your next structure can therefore be:

```text
nak/
└── agents/
    ├── DecisionAgent/
    │   ├── __init__.py
    │   ├── agent.py
    │   └── models.py
    │
    ├── AgentCreator/
    │   ├── __init__.py
    │   └── agent.py
    │
    └── Example/
        ├── __init__.py
        └── base.py
```

**`DecisionAgent` = decides. `AgentCreator` = creates. Actual agents = execute.**
